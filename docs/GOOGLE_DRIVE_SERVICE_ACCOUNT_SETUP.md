# Google Drive для AI-BOSS MVP

MVP-подключение работает через service account и одну расшаренную папку Google Drive.

## Как подготовить Google Drive

1. Создать service account в Google Cloud.
2. Включить Google Drive API в проекте Google Cloud.
3. Создать JSON key для service account.
4. На Google Drive создать корневую папку, например `AI-BOSS Companies`.
5. Расшарить эту папку на email service account с правом `Editor`: это нужно, чтобы AI-BOSS создавал личные копии инструментов. Если требуется только чтение существующих файлов, достаточно `Viewer`.
6. AI-BOSS сам создаёт подпапки компаний и папку `tools`. Для старого сценария чтения можно заранее создать подпапки, название которых совпадает с названием компании в Telegram:
   - `Альфа Балт Сервис`
   - `Компания 2`
   - `Компания 3`

Если `GOOGLE_DRIVE_FOLDER_ID` указывает сразу на папку конкретной компании, AI-BOSS прочитает эту папку напрямую, если её название совпадает с названием компании. Это удобно для одного кейса, например `Селедчик консалтинг`.

## Переменные окружения

Добавить в Vercel:

```env
GOOGLE_DRIVE_SERVICE_ACCOUNT_EMAIL=service-account@project.iam.gserviceaccount.com
GOOGLE_DRIVE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
GOOGLE_DRIVE_FOLDER_ID=google_drive_root_folder_id
GOOGLE_DRIVE_MAX_TEXT_CHARS=120000
```

`GOOGLE_DRIVE_FOLDER_ID` берётся из URL папки:

```text
https://drive.google.com/drive/folders/<GOOGLE_DRIVE_FOLDER_ID>
```

## Как пользоваться в Telegram

1. Выбрать компанию:

```text
/use Альфа Балт Сервис
```

2. Подтянуть документы:

```text
/drive
```

AI-BOSS найдёт подпапку `Альфа Балт Сервис`, прочитает Google Docs / Sheets / text / CSV и сохранит документы как источники компании.

3. Запустить анализ:

```text
/analyze
```

## Что читается в MVP

Читается как текст:

- Google Docs
- Google Sheets
- Google Slides
- `.txt`
- `.csv`
- `.md`
- `.json`

PDF, изображения и сложные офисные файлы пока сохраняются как ссылки. Их текстовое извлечение лучше добавить отдельным этапом.

## Быстрый вариант без полной интеграции

Если нужно добавить один Google Doc или Google Sheet, можно не настраивать service account:

1. Открыть доступ к файлу: `Все, у кого есть ссылка, могут просматривать`.
2. В Web открыть компанию.
3. Нажать `Добавить источник`.
4. Вставить ссылку на конкретный Google Doc / Sheet.

AI-BOSS попробует вытащить текст из публичной ссылки и использовать его в следующем анализе.

Для быстрой синхронизации публичной папки:

1. Открыть доступ к папке: `Все, у кого есть ссылка, могут просматривать`.
2. В Web открыть компанию.
3. В блоке `Интеграции и доступы` нажать `Подключить папку по ссылке`.
4. Вставить ссылку на папку Google Drive.

AI-BOSS попробует найти внутри папки Google Docs / Sheets / Slides, прочитать их как текст и сохранить как источники компании. Это проще service account, но менее надёжно: Google может не отдать публичный список папки без входа, а PDF/изображения пока сохраняются ссылками.

## Личные копии инструментов

Для работы с внешними пользователями AI-BOSS должен не только читать документы, но и создавать для каждого пользователя личную копию шаблона инструмента.

Рабочая логика:

1. В каталоге есть мастер-шаблон инструмента.
2. AI-BOSS копирует шаблон в папку конкретной компании или пользователя.
3. Сохраняет `google_file_id`, ссылку и связь с `ToolInstance`.
4. Отдаёт пользователю ссылку на его личную копию.
5. После заполнения читает документ, сохраняет snapshot и обновляет память компании.

Важно:

- мастер-шаблон не изменяется;
- пользователь работает только со своей копией;
- ссылка на документ сама по себе не считается памятью;
- памятью считается структурированный snapshot и observations, которые AI-BOSS извлёк из заполненного инструмента.
