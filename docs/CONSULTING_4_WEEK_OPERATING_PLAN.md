# Операционный план упаковки консалтинга на 4 недели v0.1

Дата: 04.05.2026

Статус: рабочий план. Документ нужен, чтобы перейти от стратегии к действиям.

## 1. Цель 4-недельного цикла

Собрать первый коммерческий эксперимент консалтингового бизнеса Александра:

> один стартовый сегмент, один первый оффер, один маршрут клиента, одна структура консультации, один артефакт после консультации и 10-20 альфа-кейсов.

## 2. Главный принцип

AI-BOSS действует проактивно как CEO-слой:

- сам готовит варианты;
- сам собирает документы;
- сам анализирует качество;
- сам предлагает следующий шаг;
- выносит Александру только ключевые развилки.

Александр утверждает:

- сегмент;
- оффер;
- цену;
- публичное обещание;
- свою роль в продукте;
- границы автоматизации AI-BOSS.

## 3. Неделя 1: карта решений и оффер

### Цель

Превратить стратегические вопросы в конкретные развилки.

### Что сделать

- утвердить стартовый сегмент;
- выбрать первый платный оффер;
- описать обещание оффера;
- определить, что пользователь получает без консультации;
- определить, что получает после консультации;
- собрать карту CEO-решений.

### Выход недели

- выбран сегмент;
- выбран оффер;
- есть черновик коммерческого описания;
- есть список решений Александра;
- есть список действий AI-BOSS без согласования.

### Решение Александра

Выбрать:

- сегмент: продажи / операционный перегруз / продажа бизнеса;
- оффер: экспресс-разбор / диагностика / спринт;
- допустимый диапазон цены для альфы.

## 4. Неделя 2: маршрут клиента и консультация

### Цель

Собрать повторяемый путь от первого сообщения до результата после консультации.

### Что сделать

- описать путь Telegram -> Mini App -> резюме -> консультация -> артефакт;
- написать сценарий приглашения в Кабинет;
- описать критерии готовности к консультации;
- собрать структуру консультации на 60-90 минут;
- определить обязательный артефакт после консультации.

### Выход недели

- карта пути клиента;
- сценарий перехода в Кабинет;
- структура консультации;
- шаблон консультационного артефакта.

### Решение Александра

Утвердить:

- структуру консультации;
- что обязательно остаётся после консультации;
- что AI-BOSS должен сделать после консультации.

## 5. Неделя 3: альфа-кейсы

### Цель

Проверить упаковку на реальных людях.

### Что сделать

- провести 10-20 пользователей через маршрут;
- фиксировать, где они теряются;
- оценивать диалоги в админке;
- смотреть, где AI-BOSS звучит шаблонно;
- проверять, понятна ли гипотеза ограничения;
- проверять, возникает ли готовность к разбору.

### Выход недели

- таблица альфа-кейсов;
- оценки качества диалогов;
- список повторяющихся проблем;
- первые выводы по офферу и маршруту.

### Решение Александра

Выбрать:

- оставляем ли сегмент;
- меняем ли формулировку оффера;
- какие 1-3 проблемы исправляем первыми.

## 6. Неделя 4: сборка повторяемого контура

### Цель

Собрать рабочий контур, который можно повторять.

### Что сделать

- обновить тексты бота и Mini App;
- улучшить объяснение гипотезы ограничения;
- финализировать консультационное резюме;
- финализировать артефакт после консультации;
- собрать минимальный dashboard альфа-кейсов;
- определить следующий продукт после экспресс-разбора.

### Выход недели

- рабочий маршрут клиента;
- первый оффер;
- консультационный процесс;
- пост-консультационный артефакт;
- список улучшений следующего цикла.

### Решение Александра

Утвердить:

- запуск платного теста;
- цену;
- формат следующего продукта;
- что масштабируем в следующем цикле.

## 7. Таблица контроля

| Направление | Метрика | Цель цикла |
| --- | --- | --- |
| Вход | новые диалоги | 10-20 альфа-кейсов |
| Активация | дошли до Mini App | зафиксировать факт, не оптимизировать заранее |
| Диагностика | завершили экспресс | понять, где бросают |
| Коммерция | запросили/приняли разбор | проверить интерес |
| Консультация | состоялась встреча | собрать реальные кейсы |
| Артефакт | создан после консультации | проверить ценность продолжения |
| Качество | ошибки из админки | выбрать 1-3 повторяющиеся |

## 8. Первый шаг прямо сейчас

AI-BOSS готовит для Александра карту решений:

1. стартовый сегмент;
2. первый оффер;
3. рабочее обещание;
4. структура консультации;
5. артефакт после консультации;
6. таблица альфа-кейсов.

После утверждения этих решений начинается цикл альфа-кейсов.
